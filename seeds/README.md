# seeds/ — дополнительные адреса функций для рекомпиляции JurassicPark100.exe

`build-android-jp100.sh` и `build-linux-jp100.sh` читают все `*.txt` и `*.log` из этой папки
(`tools/jp100_crt_seeds.py --merge seeds`) и добавляют адреса к автоматическим seeds
(таблицы инициализации CRT, RTTI/vtable, указатели на код из секций данных).

Формат `jp100-extra.txt`:

```
# комментарий
00efcf7c
0x010e0150
[rt] MISSING-FUNC 00f01234 (можно вставлять строки лога как есть)
```

Можно просто положить сюда лог запуска (`*.log`): из него берутся строки `MISSING-FUNC xxxxxxxx`
и строки, состоящие только из hex-адресов.

После изменения файлов здесь скрипт сборки сам перекомпилирует exe (ключ сборки включает sha итогового
списка seeds). Адреса вне исполняемых секций отбрасываются — см. `build/seeds/jp100-*.log`.
