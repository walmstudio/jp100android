Быстрый старт

От исходников до запуска

Сборка выполняется на ПК с Linux. JDK 17, Android SDK, NDK r27c и glslang можно установить автоматически флагом --setup.

  1. 01

    Подготовьте файлы игры

    Установите ПК-версию первого эпизода. Папка игры должна содержать исполняемый файл, библиотеки и архивы с данными:

    • JurassicPark100.exe
    • fmodex.dll
    • binkw32.dll
    • *.ttarch / *.ttarch2

    В примерах игра находится в $HOME/JPTelltale. Если путь другой, замените его в командах.

  2. 02

    Распакуйте исходники и соберите APK

    Скачайте архив по кнопке «Исходники», распакуйте его и откройте терминал в полученной папке. При первой сборке добавьте --setup, чтобы загрузить необходимые инструменты:

    Терминал Linux
    ./build-android.sh --setup --game "$HOME/JPTelltale"

    Потребуется несколько гигабайт свободного места. Готовый пакет появится в android_jp/out/JP100-port.apk.

  3. 03

    Установите порт на устройство

    Включите на Android-устройстве отладку по USB и подключите его к компьютеру. Сборка и установка выполняются одной командой:

    Терминал Linux
    ./build-android.sh --game "$HOME/JPTelltale" --install
    Установить уже собранный APK
    Через ADB
    adb install -r android_jp/out/JP100-port.apk
  4. 04

    Перенесите игру и начните играть

    Скопируйте всю папку установленной ПК-игры в корень внутреннего хранилища устройства:

    Путь на Android
    /sdcard/JPTelltale
    1. Откройте Jurassic Park Port и разрешите доступ к хранилищу. На Android 11+ может понадобиться разрешение «Доступ ко всем файлам».
    2. Нажмите «Проверить», затем «Играть».
    Важно: JurassicPark100.exe на устройстве должен совпадать с файлом, использованным при сборке.

Если что-то пошло не так

Проверка и диагностика

Игра не запускается +

Проверьте целостность JurassicPark100.exe, наличие архивов данных и разрешение на доступ к хранилищу. Для первого запуска выберите системный OpenGL ES вместо Vulkan или Zink.

Где найти журнал +

Откройте «Лог» в лаунчере или файл /sdcard/JPTelltale/Documents/jp100_run.log. Там же по умолчанию хранятся сохранения.

Дополнительные параметры сборки и сведения о совместимости — в документации проекта на GitHub.
