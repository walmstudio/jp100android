# JP100 Port

Экспериментальный порт **Jurassic Park: The Game — Episode 1** (`JurassicPark100.exe`) на Android. Исходный 32-битный x86-код игры и библиотек `fmodex.dll` и `binkw32.dll` статически перекомпилируется в C, после чего собирается в нативную ARM64-библиотеку. Windows API, Direct3D 9, ввод, звук и файловая система реализованы в прослойке совместимости.

Проект основан на наработках `me1port`. Это не эмулятор Android и не готовый магазинный порт: для сборки и запуска нужна установленная ПК-версия игры, а совместимость зависит от версии исполняемого файла и устройства.

## Требования

Для сборки:

- Linux x86-64 с Bash, Make, Python 3.8+, Zip;
- Python-модуль Capstone — при отсутствии скрипт попытается установить его в отдельное окружение;
- JDK 17, Android SDK и Android NDK r27c;
- для первоначальной установки инструментов через `--setup` — `curl` или `wget`, `unzip` и несколько гигабайт свободного места;
- оригинальная ПК-версия первого эпизода с `JurassicPark100.exe`, `fmodex.dll`, `binkw32.dll` и архивами данных `.ttarch`/`.ttarch2`.

Основная версия `JurassicPark100.exe`, на которую рассчитан runtime, имеет размер `18 051 196` байт и SHA-256 с префиксом `e686a26571e093d2`. Скрипт предупредит, если обнаружит другую сборку.

Для запуска:

- устройство Android 10 (API 29) или новее;
- процессор ARM64;
- системный OpenGL ES. Собственный рендерер D3D9 → Vulkan доступен при сборке с `libme1spv.so`; Mesa Zink и пользовательские GPU-драйверы являются экспериментальными возможностями.

## Быстрый старт

Первая сборка с автоматической загрузкой JDK, SDK, NDK и glslang:

```bash
./build-android.sh --setup --game "$HOME/JPTelltale"
```

В `--game` передаётся папка установленной игры. Вместо неё можно явно указать отдельные файлы:

```bash
./build-android.sh \
  --exe "/путь/JurassicPark100.exe" \
  --fmodex "/путь/fmodex.dll" \
  --bink "/путь/binkw32.dll"
```

При последующих сборках перекомпилируются только изменившиеся компоненты:

```bash
./build-android.sh --game "$HOME/JPTelltale"
```

Готовый пакет создаётся здесь:

```text
android_jp/out/JP100-port.apk
```

Установка на подключённое устройство с включённой отладкой по USB:

```bash
./build-android.sh --game "$HOME/JPTelltale" --install
```

Либо установка уже собранного APK:

```bash
adb install -r android_jp/out/JP100-port.apk
```

## Запуск на устройстве

1. Скопируйте папку установленной игры целиком в:

   ```text
   /sdcard/JPTelltale
   ```

   В ней должны находиться `JurassicPark100.exe`, архивы `.ttarch`/`.ttarch2` (обычно в `Pack`) и остальные данные игры. EXE на устройстве должен совпадать с файлом, использованным при сборке.

2. Установите и откройте **Jurassic Park Port**.
3. Разрешите доступ к хранилищу. На Android 11+ может потребоваться включить «Доступ ко всем файлам».
4. Нажмите **«Проверить»**, затем **«Играть»**.

Лаунчер позволяет выбрать OpenGL ES, Vulkan или Zink, включить отображение FPS и настроить режим нагрузки GEARMASS. Сохранения и журнал запуска по умолчанию находятся в:

```text
/sdcard/JPTelltale/Documents
```

Основной журнал: `jp100_run.log`. Его также можно открыть кнопкой **«Лог»** в лаунчере.

## Полезные параметры сборки

```text
--setup             скачать недостающие JDK, Android SDK, NDK и glslang
--tools ПАПКА       выбрать каталог инструментов (по умолчанию ~/me1port-tools)
--recomp            заново перекомпилировать EXE и DLL
--clean             удалить объектные файлы и выполнить полную пересборку
--opt "ФЛАГИ"       задать оптимизацию кода игры (по умолчанию -O1)
-j N                число параллельных задач компиляции
--no-spv            не собирать Vulkan-рендерер, оставить OpenGL ES
--gpu               собрать Mesa Zink и libadrenotools (долго, нужны дополнительные зависимости)
--keystore ФАЙЛ     подписать APK своим ключом
--install           установить APK через adb после сборки
-v, --verbose       показать полный вывод компиляции
-h, --help          полная справка по параметрам
```

Логи сборки сохраняются в `build/logs/`, `build/recomp/` и `build/seeds/`.

## Если игра не запускается

- Проверьте версию и целостность `JurassicPark100.exe` и совпадение файла на ПК и устройстве.
- Убедитесь, что лаунчер видит архивы `.ttarch`/`.ttarch2` и имеет доступ к хранилищу.
- Попробуйте системный OpenGL ES вместо Vulkan или стороннего драйвера.
- Посмотрите `Documents/jp100_run.log` через кнопку **«Лог»**.

Если в журнале есть строка вида:

```text
[rt] MISSING-FUNC 00f01234
```

добавьте адрес в `seeds/jp100-extra.txt` либо положите сам `.log`-файл в `seeds/`, затем повторите сборку. Подробный формат описан в [`seeds/README.md`](seeds/README.md).

## Структура проекта

- `build-android.sh` — основной сценарий сборки JP100 для Android;
- `jp100.mk` — правила компиляции перекомпилированного кода и runtime;
- `jp_launcher/` — специфичный для JP100 лаунчер и упаковка APK;
- `android/` — игровая Activity, управление, JNI и графические компоненты;
- `runtime/` — прослойки Windows/D3D9, звук, ввод и платформенный runtime;
- `settings/` — работа с настройками;
- `tools/` — рекомпилятор, анализ PE-файлов и вспомогательные утилиты;
- `seeds/` — дополнительные адреса функций для рекомпиляции;
- `out/` — сгенерированные C-модули и образы исходных EXE/DLL;
- `build/` — объектные файлы и журналы сборки;
- `android_jp/` — автоматически сгенерированный Android-проект и итоговый APK.

`android_jp/` полностью пересоздаётся при упаковке, поэтому изменения следует вносить в `jp_launcher/`, `android/`, `runtime/` и другие исходные каталоги, а не в сгенерированные файлы. Сценарии `builder.sh` и `android/build_apk.sh` относятся к базовому порту Mass Effect и не являются точкой входа для сборки JP100.

## Правовая информация

Файлы игры не заменяются этим проектом: требуется собственная легально приобретённая копия. APK и содержимое `out/` включают код, полученный из игровых EXE/DLL, поэтому не распространяйте их публично без соответствующих прав.
